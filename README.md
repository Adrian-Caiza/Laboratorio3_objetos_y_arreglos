Laboratorio #4 – Objetos y Arreglos en JavaScript
Este proyecto contiene ejemplos básicos de cómo trabajar con objetos y arreglos de objetos en JavaScript. Está diseñado con fines educativos para mostrar cómo almacenar, desestructurar y mostrar datos estructurados relacionados con videos de YouTube.

Contenido del Código
1. Objeto video
Se crea un objeto simple que representa un video individual, con propiedades como:

titulo

canal

visitas

duracion

publicado

Luego, se desestructura este objeto y se imprime su información formateada en la consola.

2. Arreglo de Objetos videos
Se define un arreglo que contiene múltiples objetos de video, simulando una lista de videos de YouTube. Cada objeto contiene:

titulo

canal

visitas

duracion

A través de un bucle forEach, se recorre la lista y se imprime en consola la información detallada de cada video, incluyendo el índice correspondiente.
